# Пакет сбора новых railway-сцен

Этот пакет **не содержит изображения или датасеты**. Он собирает проверенные официальные источники, метаданные, план 10 сцен, команды загрузки с resume, черновики запросов доступа и адаптеры для подготовки данных под `railway-person-new-scenes-v1`.

## Что уже собрано

- официальный `RAIL-BENCH data_overview.csv` на 2 500 изображений;
- сводка по источникам, сценам и камерам;
- статический train/val candidate pool без benchmark test и без OSDaR23;
- план 4 сцен RailGoerl24 + до 6 сцен RailEye3D;
- безопасные скрипты загрузки, инвентаризации и проверки архивов;
- черновики запросов RailEye3D и RAWPED.

`accepted_scenes` остаётся равным 0, пока изображения не загружены, сцены не выбраны, разметка не проверена и существующий CPU audit не выдаст PASS.

## Основной маршрут

1. Запустить `scripts/download_open_sources.sh` для RailGoerl24.
2. Отправить запрос на изображения RailEye3D. Публичные аннотации можно клонировать сразу.
3. После распаковки запустить `scripts/inventory_downloads.py`.
4. Выбрать 4 независимые последовательности RailGoerl24 и 4–6 последовательностей RailEye3D с разных станций.
5. Для каждой сцены оставить 100–300 вручную проверенных кадров и хотя бы один непрерывный фрагмент от 20 кадров.
6. Проверить минимум три точки съёмки и два условия освещения. Если второго освещения нет, не запускать обучение: добавить собственную съёмку либо запросить RAWPED.
7. Заполнить CSV проекта и выполнить существующий `audit_new_scenes.py`/CPU gate.

## Важные ограничения

- RAIL-BENCH: только академическое/некоммерческое исследование; не публиковать исходные данные; benchmark test не использовать в development.
- RailEye3D: некоммерческое использование, обязательное цитирование, запрет перераспространения.
- RAWPED: доступ по запросу, запрет перераспространения, объём около 171 GB.
- RailGoerl24: CC0, но лица не размыты; по политике проекта изображения и crops держать локально.
- OSDaR23 не считать новым автоматически: проект уже использовал этот источник, нужен точный overlap audit по scene/sequence/video ID.

## RAIL-BENCH

`metadata/railbench_static_candidates_train_val.csv` — это только статический пул для hard negatives и supplementary confirmation. Он **не выполняет** требование 20 последовательных кадров и не считается одной из 8 обязательных temporal-сцен.

Перед загрузкой RAIL-BENCH пользователь или организация должны отдельно подтвердить его условия. Скрипт требует переменную:

```bash
export I_ACCEPT_RAILBENCH_NONCOMMERCIAL_TERMS=YES
```

## Запуск

```bash
bash scripts/download_open_sources.sh /path/to/local/data_root
python scripts/inventory_downloads.py /path/to/local/data_root
```

Архивы и распакованные данные не добавлять в Git и публичные ZIP.
